SAFE PRACTICE SET

All records in demo_log.txt are fictional. There are twelve numbered records.

1. In CFL FileSplitter For Uploading Large Files To Claude.exe, select Verify a set, then choose either:
   Demo\Readable_UTF8\Parts
   Demo\Encoded_TXT\Parts
   Both represent the same original demo_log.txt.

2. Select Rejoin a set and choose the same Parts folder. Save to a NEW filename
   such as demo_restored.txt. The original hash must match.

3. For an initial Claude test, use ONLY ONE of those Parts folders.
   Attach all its part-*.txt files, CLAUDE_JOINER.txt and CLAUDE_INSTRUCTIONS.txt.
   Ask Claude to reconstruct the original with code, verify SHA-256, then report
   the number of numbered records and the final Unicode line.
   If the account rejects or truncates the files, stop rather than guessing.

Do not mix the two sets: they have different set identifiers by design.
The small demo chunks use an internal test limit below the GUI's 1 MB minimum.
